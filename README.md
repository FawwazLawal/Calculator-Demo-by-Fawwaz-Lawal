# Basic Calculator Demo

This project is a simple web-based calculator built using **HTML** and **JavaScript**.

The purpose of this project is to demonstrate the fundamentals of web development, including:

- HTML structure
- JavaScript functions
- User input handling
- Basic arithmetic operations

---

# Features

The calculator currently supports:

- Addition
- Subtraction
- Multiplication
- Division

Users enter two numbers and select an operation to calculate the result.

Calculator-App-ChatGPT

├── basic-calculator.html # Main webpage

# How It Works

1. The user enters two numbers into the input fields.
2. The user clicks one of the operation buttons.
3. JavaScript retrieves the input values.
4. The selected math operation is performed.
5. The result is displayed on the webpage.

# Technologies Used

- HTML
- JavaScript

No external libraries or frameworks are required.

# Running the Project

To run the calculator:

1. Open the project folder.
2. Open `basic-calculator.html` in a web browser.

Or use the **Live Server extension in VS Code**.
